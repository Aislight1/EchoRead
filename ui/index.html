语料与目录

    音色工作台（试听 / 设计 / 克隆）

    引擎与供应商在上方「语音输出」卡里选；这里管理音色本身：试听、文字设计、参考音频克隆。
    选一个音色点「读英文 / 读中文」听效果。英文样本和中文样本各一段。
    MiMo 会用这段描述生成音色，返回的 voiceId 会存进「我的音色」，之后能在练习页直接选。
    和「文字设计」的区别：设计是靠一段文字描述凭空造一个音色； 克隆是照着一段真人音频复制音色 —— 想要某个具体的人的声音，用这个。 不需要训练，几秒钟就好。
    参考音频建议 3–10 秒、单人、干净无背景音乐。 克隆后程序会把这段音频复制保存下来 —— 因为每次合成都需要它 （MiMo 返回的 voiceId 不能单独用来合成，这是它的接口限制）。

      语音输出（用哪个模型说话）

      所有语音合成（发音练习示范音、听力朗读、跟读、试听）都由这里决定。 点供应商卡片或引擎格切换；⟳ 拉模型列表，⚡ 实测响应速度。
      用下面设置的固定试听句，同一个音色只合成一次，之后走缓存不再调 API。
      比如：发音练习用 MiMo（英文口音标准），听力朗读用本地可露希尔。

      🎤 语音识别模型

      用 paraformer-realtime-v2，特点是返回逐词时间戳， 这是判断"哪个词读错"的基础。
      💡 基于本应用的语音处理经验，推荐 paraformer-realtime-v2——返回逐词时间戳，诊断对齐/发音纠错/字幕时间轴校准都依赖它，在本应用兼容性最好。选完就点「💾 保存」即刻生效，不用找页底的大保存。
      🎤=录音 5 秒实测：识别出你说的内容即模型/Key 生效。
      加词 →「同步到云端」建表 → 识别自动带上（听写 / 🩺诊断对齐 / 字幕转写全生效）。热词表绑定识别模型，换模型后再同步一次即可。权重 4=推荐；50=超级热词（≤50 个）。paraformer / qwen-audio-3.x 系支持。
      paraformer 约 0.29 元/时：修一句 10 秒 ≈ 0.0008 元，全文修正一小时视频 ≈ 3 分钱。匹配率低的句自动保留原时间戳。

      🎧 音频处理模型 （生成字幕 / 下载转写专用）

      ⚠ 依赖阿里云 API：本卡全部模型走 阿里云 DashScope（需在上方「🎤 语音识别模型」卡填好阿里云 API Key 才能调用；语言模型那边接入阿里云的 API 也可以复用同一个 Key）。
      下载/生成字幕的转写走它（与练习识别分开）。留空/默认 = qwen3-asr-flash。
      「🩺 诊断修正」的对齐/重转写用词级时间戳根治假时间轴——omni/qwen3-asr 没有词级，无法替代此岗位。
      智能下载收尾时抽听头/中/尾三段，防静默漏转——omni 的正确岗位（不是逐句转写）。
      一体模式失败或缺翻译时自动回落转写+LLM 精翻，不会卡住。
